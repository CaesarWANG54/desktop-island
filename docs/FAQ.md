# 常见问题

## 下载后双击没反应

确认下载的是 Release 中的 `win-x64.zip`，并已完整解压。不要在压缩软件内直接运行 EXE。下载包已包含 .NET 运行环境。

本项目暂未使用付费代码签名证书，Windows 可能显示未知发布者。先核对下载来源及同一 Release 的 SHA-256 校验文件；不要为运行本项目关闭杀毒软件或全局安全设置。

## 音乐有声音，灵动岛没有显示

先在设置中选择对应音乐来源，确认官方桌面客户端已开始播放。QQ 音乐依赖 Windows 媒体会话；若客户端提供相关选项，请开启。网易云日志回退要求客户端写入本地播放日志；便携版、特殊版本、浏览器版不保证兼容。

网易云回退模式的媒体按键可能与其他播放器冲突，因此检测到其他媒体会话时会提示先关闭其他播放器。

## 有歌名，没有歌词

可能是纯音乐、暂未收录、版本无法准确匹配或歌词接口不可用。程序不会拿任意同名歌曲的歌词替代；可导入对应 LRC。QQ 与网易云的在线歌词接口属于第三方服务，不能保证永久可用。

## 一直显示 `-- FPS`

依次检查：已启用 FPS、已完成一次系统授权、游戏在前台、使用无边框全屏或窗口模式。窗口游戏可添加实际 EXE 进程名。切换游戏/场景后允许几秒钟建立新采样。

本版采集 DXGI 成功提交的帧，Vulkan/OpenGL 等路径可能无数据。不要为获得帧率关闭反作弊、修改游戏或安装注入插件。

## 每次启动又要求授权

正常启动不会请求提权。授权只用于初次配置、移动目录后的重新配置、更新采集器或卸载。先运行 `Install.cmd` 固定目录，再在设置中配置 FPS。

FPS 自动任务要求当前账户是 Windows 管理员。以另一个管理员账户填写密码，不等同于为当前标准账户启用采集；这类账户可先使用其余功能。

## 天气没有出现

首次使用没有默认城市。展开“天气”→“管理地点”搜索并添加；同名城市请根据省份/区域选择。音乐和游戏状态优先显示其内容，天气在空闲胶囊和天气页显示。

## 程序不在主屏顶部，或快捷键无效

通过托盘图标进入设置检查顶部距离。多屏时以 Windows 设置中的主显示器为准。若 Ctrl+Alt+I 被其他软件占用，可使用托盘双击展开。

## 如何手动移除便携版 FPS 任务

退出程序，以**当前用户**的管理员 PowerShell 运行下面命令。将第一行改为完整解压目录：

```powershell
$appDir = 'C:\Path\To\DesktopIsland'
$sid = [Security.Principal.WindowsIdentity]::GetCurrent().User.Value
& "$appDir\scripts\remove-fps-task.ps1" -UserSid $sid
```

## 反馈问题前

请说明 Windows 版本、程序版本、播放器/游戏版本和复现步骤。不要上传 API Key、账号 Cookie、Codex 聊天日志或完整用户目录。诊断模式是可选开发功能，诊断文件可能包含歌曲、城市和进程信息，分享前请自行检查。
