# 使用指南

## 第一次启动

完整解压 Release 下载包，双击 `Install.cmd`。程序安装到当前用户的 `%LOCALAPPDATA%\Programs\DesktopIsland`，创建桌面和开始菜单的 **Desktop Island** 快捷方式。音乐、时钟和计时不需要管理员权限。

首次引导中：

1. 选择“自动”、QQ 音乐或网易云音乐。
2. 点击“选择天气城市”，搜索城市/区县后添加。最多保存 5 个地点，可设置默认地点。没有开启 GPS 或 IP 自动定位。
3. 按需开启开机启动、游戏 FPS、Windows 通知和 Codex 提醒。
4. 点击“开始使用”。选择 FPS 后会出现一次 Windows 授权；取消不会影响其他功能。

也可以直接运行解压目录的 `DesktopIsland.exe`，保持文件夹完整即可。若移动程序文件夹，需要在设置中重新配置帧率连接和开机启动；推荐使用 `Install.cmd` 固定安装路径。

## 音乐

在官方桌面客户端中播放一首歌。胶囊显示当前和下一句歌词；悬停展开后使用播放、暂停、上一首和下一首。

同时打开多个播放器时，在设置中选择来源。网易云日志回退模式使用系统媒体键，使用时关闭其他音乐播放器。若客户端提供系统媒体控制选项，请开启。

歌词不同步时可在设置中调整提前/延后，范围为 ±5 秒。没有在线歌词时，先播放目标歌曲，再点击“导入歌词”选择对应的 LRC 文件。

## 游戏帧率

开启“游戏帧率采集”并完成首次系统授权后，后续启动自动连接。使用无边框全屏；已识别的游戏进入前台后显示小型 FPS 胶囊。

窗口游戏未被识别时，在设置里点击“选择游戏程序”，选择实际游戏 EXE，而不是启动器。也可在进程列表中添加名称，不需要完整路径。

游戏状态默认鼠标穿透，不抢焦点。按 **Ctrl + Alt + I** 展开。离开游戏模式停止采集；关闭灵动岛后，采集器停止工作并在待机期限内退出。设置中可以关闭自动游戏模式或 FPS 采集。

## 天气、时间与计时

- 时钟使用电脑当前的本地时间与时区，修改 Windows 时间设置后跟随更新。
- 天气默认每 15 分钟刷新；最低/最高温使用所选地点的当地日期。过期、缺失或无法获取的数据不会显示成 0℃。
- “计时”页切换倒计时与秒表。可使用预设时间、加减分钟或在设置里输入自定分钟数。
- 倒计时结束后出现提醒；游戏模式中不会自动展开或播放提示音。

## 通知与 Agent

Windows 通知需要同时允许系统通知和本应用访问；软件内部红点不是 Windows 通知，无法通用读取。部分系统版本对未打包应用的通知访问有限制，状态会如实显示。

Codex 提醒从 `CODEX_HOME` 或当前用户的 `.codex` 目录读取新追加的任务完成标记。自定义位置可在设置中更改，重开程序后生效。

其他 Agent 可在任务完成回调中执行：

```powershell
& "$env:LOCALAPPDATA\Programs\DesktopIsland\DesktopIsland.exe" --notify "My Agent" "任务完成" "点击查看"
```

这只是本机通知入口，不会自动修改其他 Agent 的配置。

## 更新与卸载

更新时解压新版本，退出旧版本后运行新的 `Install.cmd`。设置和缓存保留。帧率组件版本更新或安装目录变化时，设置里的“配置 / 重连帧率”会请求一次 Windows 授权。

在 Windows“已安装的应用”中卸载 **Desktop Island**。移除受保护的帧率组件时需要一次授权。默认保留设置与缓存；如需一起清除，可在卸载前运行：

```powershell
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\DesktopIsland\scripts\uninstall.ps1" -RemoveData
```

直接解压运行的用户可先通过包内 `scripts/remove-fps-task.ps1` 移除已启用的采集任务，再删除程序文件夹；具体参数见常见问题。
