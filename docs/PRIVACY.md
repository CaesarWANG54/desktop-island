# 隐私与网络访问

Desktop Island 没有账号系统、个人 API Key、遥测、广告或自动日志上传。首次配置没有预置城市或个人路径。

| 功能 | 读取 / 保存 | 对外请求 |
| --- | --- | --- |
| 时钟与计时 | 电脑本地时间、计时状态 | 无 |
| 音乐状态 | Windows 媒体会话；网易云回退读取本机播放日志 | 播放控制在本机完成 |
| 在线歌词 | 歌名、歌手、专辑、时长或歌曲 ID；歌词缓存保存在本机 | QQ 音乐、网易云音乐，必要时 LRCLIB |
| 天气 | 用户选择的城市、坐标、天气缓存 | Open-Meteo 天气与地名服务 |
| FPS | 前台进程名称/PID、目标进程的 DXGI 帧事件 | 无 |
| Windows 通知 | 用户允许后的系统通知内容，仅在本机内存显示 | 无 |
| Codex 提醒 | 用户开启后，在本地读取新追加日志并提取任务完成标记 | 无；不将对话内容加入提醒或发送到外部服务 |

第三方网络服务会接收到正常连接所需的 IP 地址等网络信息。在线歌词可在设置中关闭；不配置城市则不请求天气。软件不读取浏览器 Cookie、音乐账户密码或聊天 API Key。

数据目录为 `%LOCALAPPDATA%\DesktopIsland`，包含设置、计时状态、天气缓存、歌词缓存和少量本地技术日志。通知不写入持久化历史。默认不生成歌曲/进程诊断快照；显式以 `--diagnostics` 启动时会生成本机诊断文件。

日志可能包含本机路径或错误类型。不会自动发送，也不应直接公开。卸载默认保留数据；加 `-RemoveData` 可清除本工具的数据目录。

FPS 采集器位于 `%ProgramFiles%\DesktopIsland\FpsCollector\<当前用户 SID>`，其配置中的用户 SID 和安装路径仅在安装者本机生成，不属于下载包。它通过限制到本用户的命名管道接收 PID，并校验实际连接进程；不执行客户端提供的任意命令。
